# 概要
あくまでAIは提示された情報に基づいた一般論を提示しているだけに過ぎない。
解像度や確度を上げたいなら、それに合わせた情報を提供すべき。

AGENTS.mdや、ai skillsでカスタマイズしよう

基本的に設計を性能良いモデル、実装をそこそこのモデルに任せる形が良さげ。実装時は変に推論させないほうがいいからね。そのために前もってちゃんとした実装計画を作成してもらってチェックしたうえで作業に入ったもらう形式が良き。
