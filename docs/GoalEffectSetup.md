# ゴール得点エフェクトの設定

## Inspectorの設定

1. 赤・青それぞれのゴールに配置した`GoalEffect`を使用します。エフェクトとその親のGameObjectは有効にします。
2. 各`GoalController`の`Goal Effect`へ、そのゴールの`GoalEffect`に付いているParticleSystemを割り当てます。Prefabアセットではなく、ゴール内に配置したインスタンスを指定します。
3. ParticleSystemの`Play On Awake`と`Looping`はオフにします。`Stop Action`は`None`にし、再生後もオブジェクトを再利用できる状態にします。
4. 各`GoalController`の`Match Manager`へ、試合シーンの同じ`MatchManager`を割り当てます。`Scoring Team`は、そのゴールに入ったときに得点するチームを指定します。
5. ゴールやエフェクトへのNetworkObjectの追加は不要です。各端末に同じゴールとエフェクトを配置しておきます。
6. HUDのCanvasに得点表示専用の`Text - TextMeshPro`を追加します。配置・フォント・サイズ・色はInspectorで設定し、`Raycast Target`をオフにします。
7. `MatchHudController`の`Goal Message Text`へ、そのテキストを割り当てます。GameObjectは有効のままにしてください。スクリプトが文字コンポーネントの表示を切り替えます。カウントダウンとは別のテキストを指定します。
8. 同じ`MatchHudController`の`Red Goal Message`に「赤チームが得点！」、`Blue Goal Message`に「青チームが得点！」などを設定します。文言はチームごとに自由に設定できます。空欄のチームの得点時は文字を表示しません。TextMeshPro側の文字内容は表示時に上書きします。

## 動作

サーバーでゴールの得点が受理された場合だけ、`MatchManager`が`GoalCelebration`状態へ移行して全プレイヤーとボールをその場に停止し、Host・Clientへ通知します。演出中は試合時計・操作・追加得点を停止し、HUDに得点用の文字を表示します。
文言はサーバーが同期する得点先チームから選びます。ゴール自体の色ではなく、`GoalController`の`Scoring Team`に対応します。演出中にHUDを再度有効にしても、同期された得点先から復元します。
各端末の`GoalController`は通知された得点先チームが自身の設定と一致する場合に、前回の粒子をクリアしてから子のParticleSystemも含めて再生します。
子も含めて粒子が消えた時点で完了を通知し、対象の全表示端末が完了した後にリスポーンへ進みます。得点文字は演出状態の終了時に非表示になります。その後、全プレイヤーの再配置完了を待ってカウントダウンを開始します。
画面外でも終了を検知できるよう、演出用ParticleSystemのカリングは再生時に`Always Simulate`へ設定します。親・子ともに`Looping`はオフにしてください。ループ設定がある場合はエラーを出して演出を省略します。
未設定・無効・破棄されたエフェクトは待機対象にせず、演出途中に無効化されたものは完了として扱います。途中で切断した端末は待機対象から除外します。
カウントダウン中・試合終了後など得点が受理されない場合は再生しません。過去のゴール演出を途中接続の端末へ再生する処理はありません。

## 動作確認

- 赤・青それぞれのゴールで得点し、入った側だけがHost・Clientの両方で再生されること。
- リスタート後に同じゴールへ再び得点しても、先頭から再生されること。
- カウントダウン中や試合終了後の接触で再生されないこと。
- シーン開始直後に自動再生されず、得点の通知時だけ再生されること。
- `Goal Effect`未設定の場合は警告が出るが、得点処理は継続すること。
- 得点直後は元の位置で停止し、粒子が消える前にリスポーンやカウントダウンを開始しないこと。
- 演出中だけ指定した文字が表示され、リスポーン以降は非表示になること。
- Red・Blueが交互に得点した場合、Host・Clientともに得点先の文言へ切り替わること。
- エフェクトが画面外にある場合や、待機中のClientが切断された場合も、完了後にリスポーンへ進むこと。
- 得点演出中に`ResetMatch()`または`FinishMatch()`を呼ぶと、エフェクトと文字が消え、過去の完了通知で再開しないこと。
