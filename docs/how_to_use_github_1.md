## Organization(組織)について
GitHubにはOrganizationという機能があります。これを用いることによって、個人でリポジトリを作りコラボレーターとしてリポジトリに招待して制作するのではなく、チームとしてリポジトリを作成しそこにメンバーを招待する形で制作が可能になります。これだけだとあくまで責任の所在がユーザーから分離しただけになりますが、一応他にもメリットはあり、
- メンバーごとに権限を変更し、ロールを付与できる
- 複数のリポジトリをまとめて管理できる
が主なメリットです(他の機能を活用できていないだけかも)
Organizationでまとめておくと一覧で見やすくなるのと複数リポジトリが作れるのでそれだけのために設定する価値はある..と思ってます。

### Organizationの作成方法
右のユーザーアイコン->organizations->右上のNew organization
freeを選択し、`create free organization`
名前等々を設定し完了。
ただこのままの設定だと、管理者以外はread権限しかなく招待しても編集できないのでデフォルトの権限を変更する必要があります。Settingsから、`Member privileges`を選択し`Base permissios`の`Read`を`Write`に変更してね。

### リポジトリの作成
リポジトリの部分を押して作成するだけ。ここはいつも通り。

### gitignoreについて
ゲーム作るならちゃんと設定しておきましょう。templateにunityやunrealEngineの物があるので探してチェックを入れてね。gitignore自体は、git/githubでバージョン管理を行わないファイルやフォルダを指定するもの。人によって環境が違うものや容量が大きすぎるものを対象外にすることが多い。基本はテンプレートで事足りるが、エディタの設定ファイル等抜けているものもあるので気になったら設定してね。ちなみに大きなファイルを管理できるgitLFSについては後編で。
