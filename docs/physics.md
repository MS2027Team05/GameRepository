# ボール
ポリゴンの構造を平面に展開し(サイコロの展開図的な理論)、そのうえでボールを転がすシミレーションを行い挙動を実現。もちろん細かい補正はあるが。

# プレイヤー(表面移動)
プレイヤーの足元点を取得しつつ、浮いた際(地形からはみ出た=法線面の角度が変わった時)そこから最接近の点(Physics.ClosestPoint)を取得し、その法線面に沿って移動及び回転する形。

# 空中移動
移動先を指定しその座標に向かってプレイヤーの位置とを比較した線形補間で移動。指定したタイミングで指定先面の法線向きにプレイヤーを回転する。移動先は飛び出した後も変更できるため、変更した場合は最終着地点がその通りにずれる。
また、着地場所が辺の際や角、着地して最初に触れた場所がプレイヤーの足元でない場合は、もっとも近い点を取得しそこにプレイヤーの足元基準で着地するように補正を行っている(バグの原因になるため)
