# 試合開始・リスタートのカウントダウン

## Inspectorの設定

1. 試合シーンの`MatchManager`で、`Countdown Duration Seconds`を1以上に設定します。3秒なら`3 → 2 → 1`の後に開始します。
2. 同じコンポーネントの`Player Spawner`にシーン内の`PlayerSpawner`、`Ball`に試合用の`BallController`を割り当てます。これらは同じサーバーでネットワーク生成する必要があります。
3. `Match Duration Seconds`を1以上に設定します。シーン開始から自動でカウントする場合は`Start Automatically`をオンにします。オフの場合はサーバー側から`StartMatch()`を呼び出します。
4. `PlayerSpawner`のチーム別スポーン地点を設定します。開始時・得点後とも生成時の位置と回転へ戻ります。Player Prefabには`PlayerController`と`NetworkObject`が必要です。
5. ボールには既存の`Rigidbody`、`NetworkObject`、サーバー権限の`NetworkTransform`を使用します。初期位置はボールのネットワーク生成時の位置です。
6. 既存HUDのCanvasの子にカウントダウン専用の`Text - TextMeshPro`を追加します。中央アンカーで、表示領域と文字サイズを設定し、`Raycast Target`をオフにします。
7. `MatchHudController`の`Countdown Text`へ追加したテキストを割り当てます。テキストのGameObjectは有効のままにします。表示のオン・オフはスクリプトが制御します。
8. 通常の試合では`MatchManager`の`ゴール得点を1回に制限`をオンにします。この制限は1回のプレーに適用し、リスタート完了時に解除します。

## 処理の流れ

- 開始要求後、サーバー上でプレイヤー生成とボールのネットワーク生成が完了するまで待ちます。
- 開始時と得点後は同じカウントダウン処理を通ります。全プレイヤーを再配置し、移動・アクション・視点入力を停止します。ボールは所持を解除し、初期位置で物理挙動を停止します。
- 再配置中は`PreparingRestart`状態で待機し、数字を表示しません。各Ownerが位置を即時反映してサーバーへ完了を返し、接続中の全プレイヤーの応答が揃った後にカウントダウンを開始します。
- 得点時は再配置の前に`GoalCelebration`で停止し、得点エフェクトと文字を表示します。対象端末のエフェクトがすべて終了してから再配置へ進みます。
- サーバーが同期する終了時刻からHUDの数字を計算し、終了すると操作とボールの物理挙動を再開します。
- 得点後も得点と秒未満を含む残り時間を維持します。カウントダウン中は試合時計を進めません。
- カウントダウン中と試合終了後は追加得点、ボール取得、シュートを受け付けません。
- 試合終了後に新しい試合を開始する場合は、サーバーで`ResetMatch()`、`StartMatch()`の順に呼び出します。

## Editorでの動作確認

以下はHostとClientを接続した状態で確認します。ターミナルでのC#コンパイルだけではRPCや物理挙動は検証できません。

- 開始時に両端末でカウントダウンが表示され、終了前は移動やシュートができないこと。
- カウントダウン中に試合時計が減らず、終了後に減り始めること。
- Red・Blueそれぞれの得点が1回だけ加算され、全プレイヤーとボールが初期位置へ戻ること。
- 得点時はその場でエフェクト終了を待ち、その後に初期位置へ戻って数字が表示されること。カウント終了時に再度リスポーンしないこと。
- 歩行中・飛行中・視点リセット中の得点後も、復帰先の向きへカメラが即時に戻り、前の位置から追いかけたり着地補正が残ったりしないこと。FOVも通常値へ戻ること。
- カウントダウン中は歩行アニメーションが残らず、Host・Clientの双方でAnimatorの初期状態になり、再開後に移動すると再び歩行アニメーションへ切り替わること。
- Clientの通信遅延がある場合も、再配置完了前にカウントダウンを開始しないこと。再配置待ちのClientが切断された場合は、接続中のプレイヤーの完了でカウントを開始すること。
- ボール所持中の得点後に所持表示・速度補正が解除されること。
- リスタート後に再び得点でき、得点と残り時間が引き継がれること。
- 試合終了後はカウントダウンが表示されず、得点・操作が停止すること。
- カウントダウン中にポーズメニューを開いて終了を迎えた場合も、メニューを閉じるまでプレイヤー入力が再開しないこと。
- `ResetMatch()`で待機へ戻した場合に進行中のカウントダウンが終了し、`StartMatch()`で新しく開始すること。
