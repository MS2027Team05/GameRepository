# 展示・検証用ネットワーク/ファイアウォール設定ツール

展示本番やオフライン環境(インターネット未接続のルーター等)でのローカル通信マルチプレイにおいて、Windowsファイアウォールによる着信ブロックをワンクリックで解決・解除するためのツール群です。

> [!NOTE]
> Windowsの文字コード設定(Shift-JIS / UTF-8)に関わらず100%確実に動作させるため、バッチファイル内部のコンソール出力は半角英数字(ASCII)で記述されています。

---

## 含まれるファイル

1. **`Allow_GamePort.bat`** (ポート開放用)
   * Netcode for GameObjectsで使用する **UDP 7777 ポート** の受信(インバウンド)を許可する規則をWindowsファイアウォールに登録します。
   * 「ドメイン」「プライベート」「パブリック」すべてのプロファイルに適用されるため、スタンドアロンルーター接続時(未識別ネットワーク/パブリック扱い)でも通信がブロックされません。
   * Unity Editor上でのプレイおよびビルド済みexeの両方に対応します。

2. **`Delete_GamePort.bat`** (設定解除用)
   * 上記で作成したファイアウォール規則(`MS2027_GamePort_7777`)を削除します。
   * 展示終了時や検証後にPC環境を元に戻す場合に使用します。

---

## 使い方

1. ホストとなるPCで **`Allow_GamePort.bat` を右クリック** します。
2. メニューから **「管理者として実行」** をクリックします。
3. UAC画面(「このアプリがデバイスに変更を加えることを許可しますか？」)で **「はい」** を選択します。
4. 黒い画面に **`[SUCCESS] Firewall rule registered successfully.`** と表示されたら完了です。キーを押して閉じてください。
5. 展示や検証が終了し設定を元に戻したい場合は、同様に **`Delete_GamePort.bat` を右クリックして「管理者として実行」** してください。

---

## トラブルシューティング

* **Q. 通常のダブルクリックで開くとどうなりますか？**
  * `[FAILED] Administrator privilege is required.` (管理者権限が必要です) と表示されて停止します。勝手にウィンドウが閉じることはありません。画面に案内が出る通り、右クリックから「管理者として実行」を行ってください。
* **Q. クライアントPC側でも実行が必要ですか？**
  * 原則として不要です。ホスト側PCのみ実行されていれば通信は成立します。
* **Q. ポート番号を変更した場合は？**
  * `NetworkConnectManager` 等でポート番号を `7777` 以外に変更した場合は、バッチファイル内の `PORT=7777` の数値を該当ポートに書き換えて実行してください。
